# Security

## Official source
The official repository is https://github.com/bhavya-in-sf/fridge-screen.
Download the app only from its Releases page. Forks and third-party downloads are not reviewed or endorsed by this project.

## Report a vulnerability privately
Use https://github.com/bhavya-in-sf/fridge-screen/security/advisories/new to report suspected security issues.
Include the app version, macOS version, impact, and minimal reproduction steps. Do not include credentials or private screenshots. Do not publish exploit details in public issues before maintainers have reviewed the report.

This is a volunteer-maintained beta with no guaranteed response time. Only the latest beta is actively maintained. Current downloads are ad-hoc signed, not Apple notarized or independently security-audited.

## Project boundaries
Screenshots stay local. No accounts, analytics, or screenshot uploads. Original screenshot files must remain untouched. Changes to networking, permissions, dependencies, builds, or release processes require explicit maintainer review.
